# 🧠 george.mind — The Neural Connectome & Spatial Portfolio

An interactive, 3D spatial neural atlas and personal connectome mapping the mind, engineering research, and ecosystem initiatives of **George Karani**.

Built with **Next.js**, **Three.js / React Three Fiber**, **GLSL Shaders**, and **Tailwind CSS**.

---

## 🗺️ The Connectome Architecture (7 Lobes)

```
                       [ 01. Physical AI & Reflexes ]
                                     |
    [ 02. Silicon & Low-Level ] ---- ( CORE ) ---- [ 03. Ecosystem & Salons ]
                                     |
    [ 04. Movement & Endurance ] ----+---- [ 05. Global Transits (NBO/SF/NYC) ]
                                     |
                       [ 06. Inner Monologues & Tribe ]
```

- **Fast & Curious (JSAE Challenge)**: High-speed kart MPC dynamics (~43s pace), sensor fusion, stuck recovery.
- *Core Philosophy*: Moving beyond slow autoregressive text tokens toward low-latency physical reflexes.

### 2. **Compute Core — Silicon & Low-Level Edge**
- **Hades-V**: 32-bit pipelined RISC-V processor from scratch in SystemVerilog.
- **On-Device Micro-Agents**: Sub-3B FunctionGemma (270M–1B) & LiteRT local tool calling without cloud egress.
- **Greta Engine**: High-performance Rust daemon tracking window and telemetry states.

### 3. **Broca’s & Frontal — Ecosystem & Builder Salons**
- **Startup Grind & CMX Nairobi**: Leading builder communities, developer hackathons (ClawCamp), and founder cohorts.
- **Physical AI Salons**: Curated builder salons in San Francisco (Corgi SF) and New York (Corgi NYC).
- **FrontforumFocus**: 40+ podcast episodes dissecting climate tech, robotics, and African tech infrastructure.

### 4. **Somatosensory — Movement, Sports & Endurance**

### 5. **Spatial Coordinates — Global Transits & Constellations**

### 6. **Default Mode Network — Inner Monologues & Field Notes**
