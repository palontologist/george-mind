## Sending it

**Dashboard:** event manage page → **Blasts** (or Message Guests) → compose → pick recipients by **status** and/or **ticket type** → send now or schedule.

**Notes**
- Blasts count against your **calendar's send limit**, same as invites sent from the dashboard. Don't burn it on a second blast to the same people.
- Schedule rather than send now if you're editing the date at the same time — the blast should land after the page is correct.
- Target by ticket type for SF: `Standard` / `Accelr8` (Require Approval) / `Request to Join` are separate audiences. Pending ones need approval, not a blast.

**Luma has an official MCP server** at `mcp.luma.com` — connect an AI app (Claude, ChatGPT) and you can blast, approve guests, list ticket types, and change the event date by asking in plain language. Worth wiring up if you're running both cities.
